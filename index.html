4. YouTube Video

Video YouTube dapat ditampilkan pada halaman HTML menggunakan elemen <iframe>.

Contoh YouTube

Struktur Pada HTML5

        <iframe
        width="560"
        height="315"
        src="https://www.youtube.com/embed/VIDEO_ID"
        allowfullscreen>
        </iframe>

YouTube Autoplay

Parameter autoplay=1 dapat digunakan untuk meminta video diputar secara otomatis.

YouTube Loop

Parameter loop=1 dapat digunakan untuk mengulang video.

YouTube Controls

Parameter controls=0 dapat digunakan untuk menyembunyikan kontrol player.

5. HTML Geolocation API

Geolocation API digunakan untuk mendapatkan posisi geografis pengguna.

Privasi: Browser akan meminta izin kepada pengguna sebelum mengakses lokasi.

Data yang Diperoleh

Property Keterangan

6. HTML Drag and Drop API

Drag and Drop API memungkinkan elemen HTML dipindahkan dengan cara menyeretnya.

Contoh Drag and Drop

Area 1

Seret gambar dari sini.

Area 2

Letakkan gambar di sini.

Konsep Drag and Drop

  1. Elemen menggunakan draggable="true".
  2. ondragstart dijalankan ketika proses drag dimulai.
  3. dataTransfer.setData() menyimpan data elemen yang dipindahkan.
  4. ondragover menentukan area yang menerima drop.
  5. ondrop dijalankan ketika elemen dilepaskan. 

function allowDrop(ev) {
    ev.preventDefault();
}

function drag(ev) {
    ev.dataTransfer.effectAllowed = "move";
    ev.dataTransfer.setData("text/plain", ev.target.id);
}

function drop(ev) {
    ev.preventDefault();

    var id = ev.dataTransfer.getData("text/plain");
    var item = document.getElementById(id);

    if (item) {
        ev.currentTarget.appendChild(item);
    }
}
}

7. Kesimpulan

HTML5 menyediakan berbagai elemen multimedia yang dapat digunakan untuk membuat halaman web interaktif.

Elemen <audio> digunakan untuk audio, sedangkan <video> digunakan untuk video.

Video YouTube dapat disematkan menggunakan <iframe>.

HTML5 juga menyediakan API seperti Geolocation API dan Drag and Drop API yang dapat digunakan bersama JavaScript.
